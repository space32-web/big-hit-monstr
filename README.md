# КНН трекер

Расписание группы, кнопка входа на пару, ДЗ и напоминания на почту. Работает бесплатно на GitHub:

- **GitHub Pages** (`docs/`) — приложение для телефона и ПК, ставится на главный экран.
- **GitHub Actions** — каждые 2 часа забирает `КНН.xlsx` с Яндекс Диска (`schedule.yml`),
  каждые 10 минут проверяет, пора ли слать письмо (`notify.yml`).
- Все данные в репозитории зашифрованы паролем `DATA_KEY` (AES-GCM), поэтому репозиторий может быть публичным.

## Настройка

| Где | Что |
|---|---|
| `config.json` → `schedule` | ссылка на публичную папку Яндекс Диска (`publicKey`) и путь к файлу (`path`) |
| `config.json` → `notify` | за сколько минут напоминать, время утренней сводки |
| Secrets репозитория → `MAIL_USER` | ящик mail.ru — с него и на него идут письма |
| Secrets репозитория → `DATA_KEY` | пароль шифрования (лежит локально в `secrets.local.txt`) |
| Secrets репозитория → `MAIL_PASSWORD` | пароль приложения mail.ru |
| Приложение → «Ещё» | токен GitHub для сохранения ДЗ с этого устройства |

## Письма

- **07:00** — пары на сегодня и открытые ДЗ;
- **за 20 минут до пары** — ссылка на комнату, имя для входа, ДЗ по предмету;
- **после последней пары** — напоминание проверить ДЗ в MAX.

GitHub запускает задачи по расписанию с задержкой до 5–15 минут, поэтому напоминание стоит за 20 минут.

## Локально

```bash
npm install
npm run serve          # приложение на http://localhost:8080
DATA_KEY=... npm run fetch
DATA_KEY=... node scripts/notify.mjs --dry --now 2026-06-02T17:15
```
