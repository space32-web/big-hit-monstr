# КНН трекер

Расписание группы, кнопка входа на пару, ДЗ и напоминания на почту. Работает бесплатно на GitHub:

- **GitHub Pages** (`docs/`) — приложение для телефона и ПК: https://space32-web.github.io/big-hit-monstr/
- **GitHub Actions** — каждые 2 часа забирает `КНН.xlsx` с Яндекс Диска (`schedule.yml`),
  каждые 10 минут проверяет, пора ли слать письмо (`notify.yml`).

## Пользователи и шифрование

У каждого свой пароль. По паролю находится личный файл `docs/data/users/<id>.enc.json`
(ФИО, группа, ДЗ), зашифрованный этим паролем. Внутри лежит общий ключ, которым зашифрованы
расписание всех групп (`schedule.enc.json`) и преподаватели с комнатами (`shared.enc.json`).
Расписание подтягивается для групп, указанных в профилях.

Новый пользователь:

```bash
DATA_KEY=<общий ключ> node scripts/users.mjs add "Фамилия Имя Отчество" 3426
```

Пароли и общий ключ лежат локально в `secrets.local.txt` (в репозиторий не попадает).

## Настройка

| Где | Что |
|---|---|
| `config.json` → `schedule` | ссылка на публичную папку Яндекс Диска (`publicKey`) и путь к файлу (`path`) |
| `config.json` → `notify` | за сколько минут напоминать, время утренней сводки |
| Secrets → `DATA_KEY` | общий ключ данных |
| Secrets → `OWNER_KEY` | пароль того, кому идут письма |
| Secrets → `MAIL_USER`, `MAIL_PASSWORD` | ящик mail.ru и пароль приложения |
| Приложение → «Ещё» | токен GitHub для сохранения ДЗ с этого устройства |

## Письма

- **07:00** — пары на сегодня и открытые ДЗ;
- **за 20 минут до пары** — ссылка на комнату, имя для входа, ДЗ по предмету;
- **после последней пары** — напоминание проверить ДЗ в MAX.

GitHub запускает задачи по расписанию с задержкой до 5–15 минут, поэтому напоминание стоит за 20 минут.

## Локально

```bash
npm install
npm run serve          # приложение на http://localhost:8080
DATA_KEY=... npm run fetch
DATA_KEY=... OWNER_KEY=... node scripts/notify.mjs --dry --now 2026-06-02T17:15
```
